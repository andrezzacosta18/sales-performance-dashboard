# Sales Performance Dashboard | Power BI

## Project Overview

This project focuses on analysing sales performance using Power BI, with the aim of exploring revenue, customers, products, regions and gross margin.

The dashboard is organised into three sections:

- **Overview:** Main sales KPIs and overall performance.
- **Detailed Analysis:** Sales and profitability by product, category and region.
- **Sales Trends:** Monthly and yearly performance comparisons.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modelling
- Data Visualisation

## Analysis

The project includes revenue analysis, product contribution, regional performance and time intelligence measures such as Year-over-Year (YoY), Month-over-Month (MoM) and Year-to-Date (YTD).
